## Key mechanisms added this session

### Tag noise filter — [pipeline/tag_filter.py](pipeline/tag_filter.py)
Drops 4 Last.fm tag-noise classes before write, wired into Phase 4
([enrich_metadata.py](pipeline/enrich_metadata.py)):
1. Radio stations (frequency signature, e.g. "wsum 91.7 fm madison")
2. Artist-name-as-tag (matched against the library's own artist set, per-run)
3. Personal "my …" tags ("my top songs")
4. Specific years ("2016") — **decades kept** (90s, 2010s)

A protected allowlist (14 moods + core genres + reaction words) prevents
over-blocking when an artist name == a genre word. Tests: `tests/test_tag_filter.py`.

### Mood classification (Phase 6) — [pipeline/classify_moods.py](pipeline/classify_moods.py)
Priority: Claude verdicts > audit-direct > audio centroid > null. The 14 moods:
Fast, Moody, Slow, Heavy Bass, Dance, Sad, Groove, Heartbreak, Dark, Love, Hype,
Uplifting, Happy, Sunny. `CENTROID_SUPPRESSED_MOODS = {Dark, Fast, Heartbreak}`
(suppressed only on the centroid path; Claude/audit hits for them still emit).

**Claude batch verdicts** are generated by
[scripts/write_mood_results.py](scripts/write_mood_results.py) — a dict of
`batch_index -> [moods]` that is the **version-controlled source of truth**.
It writes `inputs/claude_mood_results.jsonl` (gitignored, per owner's inputs/
policy), which Phase 6 applies as `mood_source="claude_batch"`. To change a
verdict: edit the dict in that script, re-run it, then re-run phases 6→8.
